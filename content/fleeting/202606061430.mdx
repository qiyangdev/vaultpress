Question: quoting and summarizing are not the same as understanding. How can a reading note become my own judgment?

Possible path:

1. Write down the original argument.
2. Explain it in my own words.
3. Add a concrete situation where it applies.
4. Distill it into a [permanent note](../permanent/202606061440.mdx).
